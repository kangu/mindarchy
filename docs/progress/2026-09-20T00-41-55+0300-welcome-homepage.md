# Welcome homepage

## Initial Prompt
Design a modern minimalist welcome screen showing the six latest maps as large snapshot thumbnails in a 3×2 grid. Start here instead of creating a document automatically; support new-map creation and recent reopening.

## Plan
Use the existing shell palette and recent-file history. Render file-backed snapshots asynchronously. Add a responsive homepage and reuse its untouched editor for the first map. Preserve explicit file launches and unfinished recovery. Validate with fast suites, selected offscreen UI/startup cases and rendered screenshots.

## Proposed Next Steps
Review the homepage in everyday use. Verify native caption controls and dialogs on macOS, Linux and Windows during release validation.

## Implementation Summary
Added the welcome homepage with six large preview cards, New Map/Open Map, keyboard access, hover/focus states and loading/error/empty states. Snapshot previews use the export renderer on Qt's image worker, keyed by file modification time and size. The grid adapts from three to two or one column. Normal desktop launches and Dock reopening show Home; explicit files and new-map requests bypass it. The first map reuses the existing window. Unfinished recovery and tab order are preserved; the untouched homepage does not generate recovery snapshots. Added native-platform guards so startup cases can be tested offscreen. macOS Release build and all four fast suites passed; three startup/recovery cases and the responsive thumbnail/reopen/new-map UI case passed offscreen. Inspected screenshots including the user's recent maps. The full UI/native suites were skipped per development policy. Opened the rebuilt homepage separately to preserve the current working session.
