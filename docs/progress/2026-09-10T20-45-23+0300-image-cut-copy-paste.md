# Implementation Summary
Image copy now publishes standard image pixels plus Mindarchy metadata, retaining encoded image data, display size, and placement. Cut removes only the image after copying it. Paste attaches to the selected node or replaces its image with one undo checkpoint. Supports transfers between documents and ordinary image clipboard data from other apps. Branch copy/paste remains available when an image is not selected. Added Cut/Paste image context actions and updated both keyboard shortcut tables and README.

Validation: model tests passed for cross-document transfer, metadata retention, cut/copy, replacement, undo/redo, external images, and rejecting text.
