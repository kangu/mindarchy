# macOS Test Tiering

## Initial Prompt

Clean up the macOS build process so testing is fast and doesn't flicker windows on screen. Evaluate which window-management tests are critical (must run on every change) versus opt-in (run before release / when touching native window code), and re-tier the suites accordingly without changing any test assertions.

## Plan

Four tasks, per `docs/superpowers/plans/2026-09-21-macos-test-tiering-plan.md` (spec: `docs/superpowers/specs/2026-09-21-macos-test-tiering-design.md`):

1. **CMake tier rewiring** — introduce `native_tests` (`macapplication`, `macwindow`, `windowplacement`, `application`) with `LABELS "slow;native"` + shared `RESOURCE_LOCK native_desktop`, aggregate target `mindarchy-tests-native`; relabel `collaboration_store` / `collaboration_engine_bridge` as `fast;offscreen`.
2. **windowplacement offscreen split** — move the three AppKit-free slots (`geometryValidation`, `panelVisibilitySurvivesRestartAndResize`, `nativeHyprlandRestore`) verbatim into a new offscreen `windowplacementoffscreen_test` (fast label); native suite keeps zoom/AppKit-crisp cases (6 slots).
3. **dev.py + release scripts** — `dev.py native` mode (opt-in, `-L '^native$'`), `full` filters native out (`-LE '^native$'`), `check` stays `-L '^fast$'`; `release-macos.py` and `release-windows.ps1` run two-phase (non-native leg, then native leg) so release coverage is unchanged; docs + AGENTS policy updated.
4. **Native leg verification + progress notes** — this file.

## Implementation Summary

All four tasks landed on `codex/evaluate-sharing` (commits `ecc7def`, `77caf40`, `045254d`, this docs commit).

- `CMakeLists.txt`: `native_tests` membership + `slow;native` labels, `mindarchy-tests-native` aggregate target, collaboration suites promoted to `fast;offscreen` with `TIMEOUT 60`.
- New `tests/windowplacementoffscreen_test.cpp` runs the geometry/visibility/Hyprland-restore logic with no AppKit linking and never opens windows.
- `scripts/dev.py`: `native` mode added; `full` = fast + offscreen + slow-offscreen (ui) with native excluded; `native` builds `mindarchy-tests-native` then runs `-L '^native$'`.
- `scripts/release-macos.py` / `scripts/release-windows.ps1`: two-phase ctest (`-LE '^native$'` then `-L '^native$'`), `SkipTests` skips both legs.
- `docs/development-pipeline.md` tier table + AGENTS.md test policy updated (`full` = no-flicker validation; `native` = opt-in, runs before release packaging).
